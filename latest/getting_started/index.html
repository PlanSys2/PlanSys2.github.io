Getting Started

This page installs PlanSys2 and runs its first example: a robot that plans and executes how to go from one room to another, recharging its battery on the way.

Installation

Build PlanSys2 and its examples from source as Build and Install explains.

Running the example

  1. In a terminal, start PlanSys2 with the domain of the example and the processes that perform its actions (simulated: each one takes the time the plan gives it):

    source ~/plansys2_ws/install/setup.bash
ros2 launch plansys2_simple_example plansys2_simple_example.launch.yaml

  2. In another terminal, open the PlanSys2 terminal:

    source ~/plansys2_ws/install/setup.bash
ros2 run plansys2_terminal plansys2_terminal

  3. Load the problem of the example: its rooms, the robot leia at the entrance with low battery, and the goal of being in the bathroom. The commands are in the commands file of the example, which source runs:

    source <path to plansys2_simple_example>/share/plansys2_simple_example/launch/commands

    ros2 pkg prefix plansys2_simple_example tells the path. The file contains commands such as:

    set instance leia robot
set instance entrance room
set predicate (connected entrance dinning)
set predicate (battery_low leia)
set predicate (robot_at leia entrance)
set goal (and(robot_at leia bathroom))

  4. Ask for a plan, and run it:

    get plan
run

    The terminal shows the progress of each action, and Successfully finished at the end.

What next

  • Terminal Usage explains every command of the terminal.

  • The other tools show what PlanSys2 knows and does while a plan runs: the TUI with its plan log, and the execution trace.
